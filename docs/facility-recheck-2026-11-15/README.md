## 四、数据在、但没渲染出来（逐项排查）

### 4.1 运行时实测：无整批失效

引用 `docs/acceptance/spatial-render-rescan-2026-11-15/` 的 CDP 全场景扫描：7,875 个 mesh / 6,494,538 顶点，**顶点含 NaN 的 mesh 0 个、包围盒含 NaN 的 mesh 0 个**；6,123 个不可见 mesh 均为远景 LOD（FireEscapesFar 与 24 顶点小件），非异常。
该项目历史上确有一次「公园 `pts` 未扁平化 → NaN 顶点 → 合并几何包围盒被污染 → 整组被视锥剔除」的事故，本轮同类风险为 0，`ShuyangParks` / `ShuyangParkBlocks` / `Mapped-path` / `Mapped-plaza` 均 `visible: true`。

### 4.2 隐藏量与替代量对齐

`ShuyangCityBlocks.userData.buildingCounts`：source 9,977 / rendered **9,910** / explicitReplacements 66 / fullyCovered 1 / replacedByLandmarks 67 / clipped 15 / clipFailures **0**。
9,977 − 66 − 1 = 9,910。67 条替代中 31 条来自 `GEO.supersededSourceIndices`（30 条万顺 Overture 粗块 + 体育公园用地 way/1455053507），其余来自 `PHOTO_LANDMARK_SITES.sourceBuildingIndices`（如大润发 → index 3046），均有地标模型接替——**没有一栋楼被隐藏却没有替代体量**。

### 4.3 台地遮挡：常规铺装全部在台地之上

街区台地顶面 0.22 m；`urban-context.js` 按类型抬高：parking 0.245 / green 0.235 / plaza 0.250 / path 0.255 / 球场 0.27–0.28。
raycast 实测：虞姬中轴 0.245、烈士中轴 0.245、烈士广场 0.250、沭河东岸步道 0.095（该处无台地覆盖，可见）。**园路、广场、球场没有被台地埋掉。**

两处次级问题：
- `school-grounds.js` 校门 apron 固定在 **y=0.085**；模型估算 27/40 所学校的校门铺装落在 0.22 m 台地/人行道范围内，会被盖住（校名牌在 2.62/3.32 m，不受影响）。属装饰性缺陷，建议统一抬到 0.245。
- `park-interior.js` 自建的园路缎带 `PAVE_Y=0.095`，在虞姬/南湖与台地重叠处被盖；但同一批园路已由 `urban-context` 的 path 层（0.255 m）绘出，**画面不缺**，这层是重复几何。
