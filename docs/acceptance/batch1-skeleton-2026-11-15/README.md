# 批1 城市骨架 · 2026-11-15

设施清单里“建议批次 = 批1 城市骨架”共 44 条（12 条 P0 / 32 条 P1）。本批按“先核影像、再落几何”的顺序处理医院、商业综合体与门户设施：**不新增来源里没有的楼栋**，只做四类事——补身份（名称/类别）、修正明显错误的体量、补影像可核实的场地与看台、把被替代的粗块标 superseded。

## 来源与纪律

- 卫星影像：高德 z18（`amap-satellite-z18-20261115`），0.494 m/px，经 GCJ-02→WGS84 反算后投到项目米制。**拍摄日期未知**，`imageAcquired` 保持 `null`；检索日期 2026-11-15 只记为 `retrievedAt`。
- 逐站点底图与叠加见 [imagery/](imagery/) 及 `metadata.json`（含 world 范围、100 m/50 m 网格、既有 OSM/Overview/Reviewed 轮廓，绿色为本批新增几何）。
- 实测与推断分离：`source`（OSM/Overture）不动；高度推断写 `heightSource`，几何推断写 `geometryReference.accuracyNote`（约 ±5～8 m，不是逐栋实测）。
- 逐条记录：`tools/data/shuyang/batch1-facility-traces.json`（人工判读）→ `tools/build-batch1-facilities.py` → `reviewed-batch1-buildings.geojson` / `batch1-facility-surfaces.json` / `batch1-massing-overrides.json`。

## 校验

- 新增 6 项回归（`tests/batch1-facilities.test.mjs`）：影像参考字段、看台环替代用地且原记录保留、跑道/内场环、中山医院层数推算、停保场地表、未做项声明与“不超出来源生成”。
- `node --test tests/*.mjs`：206 项中 199 通过；7 项为既有 Overpass 测试，需要 Bash，本机（Windows）无 `bash` 而失败，与本批无关。
- 影像复核：看台/跑道/内场与真实跑道白线对齐后，中心偏差从约 26 m 收敛到 3～5 m（见 `imagery/sports-center.png` 绿色叠加）。
- 3D 实机：`?debug` 下按地标传送实拍，`batch1-sports.png` / `batch1-station.png`；HUD 稳定 56～57 帧，控制台 0 错误。

## 性能

本批对渲染总量是净减少：新增 1 个看台环（40 段实体）与 3 块地表；同时把 31 条被替代的粗块从渲染层隐藏（30 条万顺 Overture 粗块 + 1 条体育公园用地）。实机在体育中心与站前两个视角测得 56～57 帧，没有出现帧率退化；draw call 未做改动前后对照，新增网格数上限为 +4。
