## 3. 参数怎么来的

沿用环 0–2 的推导，不手填：

- **倾角**：地块内已有足迹最小外接矩形长边角（硬测量）；|角| > 45° 时归一为 ±90 内的等效角。
  沭城天下 20.8°、碧桂园 20.0°、人和 −40.3° 均由该法得出。
- **行距**：影像亮度剖面的峰值间距；先按 100 m 网格裁片做 de-rotated 视图读行，再用
  `check-ring3.py` 把生成矩形叠回影像核对平行度。环 3 曾出现"肉眼读 −20°、最小外接矩形读 +20.8°"
  的矛盾，以叠加图为准定为 +20.8°（生成矩形与真实楼块平行）。
- **行排单元**：`row_runs()` 给出行中线与地块内缩的交区间，`u = s0 + 1` 起按 `width + gap`
  排布；裁切后面积 <120 m² 或与既有足迹求差后 <90 m² 的单元丢弃，计入 `droppedEdge` /
  `droppedExisting`。
- 全部参数写在 `tools/data/shuyang/imagery-districts-traces.json` 的 `districts[].patterns` 里，
  第二批统一用 `id: ring3b`，便于日后按批回滚。

## 4. 实测与推断的区分

- **实测/既有来源**：地块边界、外围道路、地块内原有 OSM/Overture 建筑一条未删未改；
  本轮**没有新增 `supersededSourceIds`**，仍是环 0 留下的 31 条 Overture 粗块。
- **影像推断（建筑）**：628 栋 `geometrySource=imagery-reconstructed-row-block`、
  `heightSource=estimate`、`imageAcquired=null`、
  `referenceId=amap-satellite-z18-20261115-rings`；`geometryAccuracyNote` 写明
  "水平误差约 ±6 m，非实测轮廓"，`heightNote` 写明按影像层数推断。
- **影像推断（通道/地面）**：`sourceSiteId=reviewed/imagery/<district>`、
  `geometryMethod=imagery-inferred ...`，中线误差 ±6 m，宽度按行距比例推定，
  **不是测绘道路中心线**。
- 影像来源：高德 z18 卫星瓦片，拼接底图 `ring2km-mosaic.jpg`，0.494 m/px，GCJ-02 反算 WGS84；
  获取时间 2026-11-15，瓦片本身无拍摄日期，按"2026 年现状近似"使用。

## 7. 限制与未做实的地方

- **第二批 11 个地块是整地块统一层数的规整回填**：层数、行距取影像多数楼型，没有逐栋识别
  异形楼、转角楼、底商裙房、屋顶加建和楼梯间凸出。单块地内若混有多层与高层，会被统一成一种。
- **通道是行距推断 + 影像核对**，不是测绘中心线；宽度按行距比例推定，可能与实际路宽差 1–2 m。
- 环 3 有 7 个地块只补了通道、没有补楼：这些地块的足迹覆盖率本来就 ≥12%，不加楼是刻意的，
  不代表其内部每栋都已核对。
- 影像 0.494 m/px，1–2 像素的门房、车棚、变电箱无法稳定判读，未补；树冠与阴影遮挡处按
  可见行列外推。
- 2 km 以外（环 4 及更大范围）本轮未处理；环 3 外缘的农田与在建工地按影像记为非建设面，
  不是"已建成"。
